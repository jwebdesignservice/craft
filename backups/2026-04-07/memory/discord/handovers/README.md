# Discord Handovers Directory

This directory stores handover documents for Discord channels created before context resets.

## Purpose
Handovers ensure continuity across resets in Discord channels by capturing:
- Current task and goal
- Progress (completed, in progress, blocked)
- Important context and decisions
- Next steps
- Channel-specific state

## File Naming
Format: `<channel-name>-YYYY-MM-DD-HHmm.md`

Examples:
- `kol-vault-2026-03-12-1534.md`
- `buy-the-whip-2026-03-11-2145.md`
- `general-2026-03-12-0923.md`

## Retention
- Last 7 days: Keep all handovers
- 8-30 days: Keep one per day per channel (most recent)
- 30+ days: Archive or delete
