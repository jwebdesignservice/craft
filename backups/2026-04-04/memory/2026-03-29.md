### What was built today

#### Bug fixes
- Table `---` separator rows (markdown) were rendering as data rows — fixed with regex filter in `FormattedBody`
- Body font size change not working — `FormattedBody` now accepts `bodySize`/`bodyColor`/`bodyWeight` props; outer wrapper no longer sets `fontWeight` (was overriding children)
- Party fields losing focus after 1 keystroke — `Field` was defined inside `EditableParties`, causing remount on every render. Fixed by hoisting to `PartyField` as top-level component
- `saveContract` was fire-and-forget — changed to `await saveContractAsync` so contracts reliably persist before response returns
- Stale `.next` cache causing `PageNotFoundError` on local builds — resolved by `Remove-Item -Recurse -Force .next` before rebuild
